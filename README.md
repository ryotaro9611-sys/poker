# TRIP LEDGER（ポーカー遠征収支）

海外ライブポーカー（キャッシュゲーム）遠征の、プレイ時間・成績・遠征全体の損益を記録する日本語Webアプリです。
iPhone の Safari 向けに作っていて、Mac のブラウザでも使えます。

- ログイン・サーバー・有料サービス・APIキーは不要
- 記録はその端末のブラウザ内（localStorage）だけに保存
- 一度オンラインで開けば、オフラインでも起動・記録・閲覧が可能（Service Worker）
- 外部への通信は為替レートの取得だけ（送るのは通貨とプレイ日のみ）

## 開き方

ビルド不要の静的ファイルです。**HTTPS で配信する必要があります**（オフライン機能と iPhone のホーム画面アプリ化に必要）。

- **公開する場合**：このフォルダを GitHub Pages / Cloudflare Pages / Netlify などにそのまま置きます（いずれも無料）。
- **Mac で試す場合**：
  ```bash
  python3 -m http.server 8765
  ```
  を実行して http://localhost:8765 を開きます。

iPhone では Safari で開いて **共有 →「ホーム画面に追加」** してください。ホーム画面から起動すると
全画面で動き、Safari の自動データ削除（しばらく開かないとサイトのデータが消える仕組み）の対象になりにくくなります。

## ファイル構成

| パス | 役割 |
|---|---|
| `index.html` / `css/app.css` | 画面の枠とスタイル |
| `js/app.js` | 画面切り替え・共通バナー・タイマー更新・Service Worker 登録 |
| `js/store.js` | 保存層（失敗時は状態を変えずにエラー）、デモはメモリ上のみ |
| `js/actions.js` | 遠征・セッション・タイマーの操作 |
| `js/calc.js` | 成績計算と入力検証（純粋関数） |
| `js/rates.js` | 為替レートの自動取得 |
| `js/chart.js` | 累積収支グラフ（SVG、外部ライブラリなし） |
| `js/views/*` | 各画面 |
| `sw.js` | オフライン用キャッシュ（更新時は `VERSION` を上げる） |
| `js/backup.js` | バックアップ（共有シート→「ファイル」へ保存）とお知らせ |
| `js/views/tripCompare.js` | 遠征の比較画面 |
| `tests/calc.test.mjs` | 計算ルールとデモ期待値のテスト |
| `tests/e2e.mjs` | 画面操作の自動テスト（ヘッドレス Chrome。為替APIは差し替えて通信しない） |

## 為替レート

1. [Frankfurter API](https://frankfurter.dev)（各国中央銀行の参考レート）
2. 上が失敗したときは [currency-api](https://github.com/fawazahmed0/exchange-api)（jsDelivr 配信）

どちらも「プレイ日以前で最新のレート」だけを採用します。取得したレートはセッションに保存され、後から変わりません。
プレイ日か通貨を編集したときだけ取り直します（手入力レートもそのとき解除）。

## テスト

```bash
npm test
```

計算のテストと、画面操作の自動テスト（開始・休憩・精算・換算待ち・保存失敗・削除・デモ・バックアップ・オフライン・画面幅など）を実行します。
画面操作のテストには Google Chrome が必要です（場所が違う場合は `CHROME_PATH` で指定）。

## 更新の配信

`sw.js` の `VERSION` を上げてから push すると、アプリを開いたときに「新しいバージョンがあります [更新]」と表示されます。記録は更新しても消えません。
